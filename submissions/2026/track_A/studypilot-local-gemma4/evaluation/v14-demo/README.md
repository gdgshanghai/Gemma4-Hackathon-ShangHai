# V14 四场景 Demo 检查

这四条合成场景只验证 V14 的真实一夜功能闭环，不是孩子使用效果、
benchmark 或统计结论。

| 场景 | 核心输入 | 必须证明的结果 |
| --- | --- | --- |
| 正常多学科 | 数学、英语、语文任务及各自估时 | 本地 Gemma 4 通过 Native Function Calling 保存三项严格结构化任务 |
| 增量补充 | 首轮数学/英语，次轮补充历史 | 第二轮保留前三项累计清单，不丢失首轮任务 |
| 数学加练超载 | 必做任务加数学选做，容量不足 | 显示真实缺口，孩子自行接受取舍后重新得到可行路线 |
| 第二晚学习 | 第一晚记录数学书面任务最大偏差 50 分钟 | 第二晚同类任务估时上调为 50 分钟，来源为低置信度历史 |

运行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File scripts/run_v14_demo_checks.ps1
```

脚本先执行真实 LM Studio 两轮预检，再运行上述四个精确测试节点。除第一条外，
其余场景不需要模型重复生成，因为它们验证的是确定性工作流和跨夜 SQLite 事实。
