# V14 家长校准韧性验证

验证日期：2026-07-17（Asia/Shanghai）

## 结论

V14.1 暴露的复杂家长校准失败已经通过缩小模型职责解决。运行时仍使用本地 `gemma-4-26b-a4b-it` Native Function Calling，不调用云模型或 Mock：

1. Gemma 只提取科目、任务类型、分钟数组和未应用备注；
2. 服务端确定性生成保守分钟、样本数、时间、单位、置信度、动作和目标 ID；
3. 家长确认直接写入已有追加式规划参数历史，不再调用模型；
4. 模型失败时可进入简化表单或放弃，本次原始观察仍保留。

- 模型：`gemma-4-26b-a4b-it`，`Q4_K_M`，状态 `loaded`，能力包含 `tool_use`；

- 工具参数只有 `duration_groups` 和 `unapplied_notes`，每组只有 `subject`、`task_type`、`minutes`；
- 家长确认与幂等重放前后 `llm_runs` 数量不变，因此不把确定性提交写成模型成功；
- 地理“读图”消歧后，同一复杂实机用例连续 `3/3` 通过；随后完整真实 LM 门禁通过。

这些是合成家庭文本的技术验证，不是儿童使用效果或比赛成效证据。

## 降级与优先级

- 正常提取最多一次模型调用；仅 Schema 不合法时允许一次完整精简对象修复，总计最多两次；
- HTTP、连接或超时错误不自动重试；前端明确显示失败原因；

- P1 只在规范化后的科目与任务类型同时匹配时使用家长保守值；
- 至少三个真实历史样本形成 P80 后，P2 继续覆盖 P1；不匹配时回退孩子估时或领域默认值。
