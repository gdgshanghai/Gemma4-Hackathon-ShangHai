# 瓷语 Kiln Echo

> 让每一件陶瓷，都能亲口讲述自己的故事。

**瓷语（Kiln Echo）** 是一款融合 AI 视觉识别、本地大模型与语音交互的陶瓷知识导览 App。

只需拍摄或选择一张陶瓷图片，AI 导览助手「小瓷」便会从器物名称、釉色、纹饰、工艺与历史文化等角度，为你生成生动易懂的专业讲解。

应用采用温润瓷色、松石绿与鎏金元素构建视觉体系，将现代人工智能能力融入东方陶瓷美学，适用于博物馆导览、陶瓷学习、文物科普与个人收藏探索。

---

## ✨ 核心亮点

- **AI 陶瓷识别**：通过相机拍摄或从相册选择图片，快速分析陶瓷器物。
- **专业知识讲解**：生成器物名称、工艺特点、纹饰釉色与历史背景等结构化内容。
- **小瓷语音导览**：支持文字转语音，让 AI 像博物馆讲解员一样娓娓道来。
- **语音追问互动**：可直接向小瓷提问，继续探索器物背后的文化故事。
- **本地模型推理**：连接局域网内的Gemma4多模态模型，兼顾响应速度与隐私保护。
- **中英双语模式**：支持中文与英文识别讲解，满足多语言导览场景。
- **明暗主题切换**：提供温润典雅的浅色主题与沉浸式深色主题。
- **多端图片选择**：支持 iPhone、Android 系统相册，以及桌面端文件选择。

---

## 🏺 使用场景

### 博物馆智能导览

游客拍摄展柜中的陶瓷器物，即可获得自然、生动的 AI 讲解，并通过语音继续追问。

### 陶瓷知识学习

从釉色、器型、纹样、窑口与时代背景等维度认识陶瓷，降低专业知识的学习门槛。

### 收藏与鉴赏辅助

上传收藏品或感兴趣的陶瓷图片，快速获得可参考的器物特征与文化背景介绍。

### 隐私友好的本地体验

识别请求可发送至局域网内运行的 Ollama 服务，无需将图片上传至公共云端。

---

## 📱 功能流程

1. 打开 App，进入「瓷语考古助手」首页。
2. 点击 **拍摄**，或从相册中 **选择图片**。
3. 点击 **开始识别（本地模型）**。
4. 查看 AI 生成的器物名称、工艺特点与历史讲解。
5. 使用语音播放聆听讲解，或通过语音向小瓷继续提问。

## 🎨 产品设计

瓷语的界面灵感来源于中国传统陶瓷与博物馆展陈：

- 以松石绿、米白与鎏金色营造温润典雅的视觉氛围。
- 使用开片纹理启动动画，呼应哥窑“金丝铁线”的艺术特征。
- 透明背景吉祥物「小瓷」贯穿导览体验，让专业知识更亲切。
- 卡片化首页集中呈现拍摄识别、知识探索与历史记录等入口。

## 🚀 快速开始

### 环境要求

- Flutter SDK
- Dart SDK
- iOS、Android 或 macOS 运行环境
- 已安装并运行 Ollama 的局域网设备
- 支持图片输入的多模态模型

### 安装依赖

```bash
flutter pub get
```

### 配置本地模型服务

编辑项目根目录的 `config.json`：

```json
{
  "OLLAMA_BASE_URL": "http://你的局域网IP:11434",
  "OLLAMA_MODEL": "你的多模态模型名称"
}
```

确保运行 App 的设备与 Ollama 服务处于同一局域网，并且模型支持图片输入。

### 启动应用

```bash
flutter run
```

选择目标设备：

```bash
flutter devices
flutter run -d <device-id> --dart-define-from-file=config.json
```
