## 一、市场痛点

神经免疫疾病负担巨大，传统方案存在三大空白。

**疾病负担**

| 疾病 | 现状 |
| --- | --- |
| 抑郁症 | 中国约 9500 万患者，识别率不足 20%，干预依从性低 |
| 慢性疲劳综合征 / 脑雾 | 缺乏客观生物标志物，误诊率高 |
| 阿尔茨海默病早期 | 确诊时往往已错过最佳干预窗口 |
| 自身免疫病相关脑病 | 神经-免疫交叉领域长期被忽视 |

**三大空白**

- **低成本空白：** 传统 BCI 设备数万至数十万元，无法进入家庭和社区。
- **可居家空白：** 湿电极需专业人员操作，患者依从性差。
- **闭环干预空白：** 现有方案仅有筛查、无闭环物理干预，过度依赖药物。

> 节思乐定位：填补三大空白，让神经免疫早筛和物理干预走进家庭。

## 二、核心定位

非侵入式 BCI + AI，将早筛与闭环干预带进家庭。系统分为感知、分析、干预三层：

| 层级 | 模块 | 关键能力 |
| --- | --- | --- |
| 感知层 | 8 通道干电极 BCI 头环 | 可穿戴、干电极、无凝胶；采集 EEG / HRV / EDA 多模信号；重量 < 50 g，250 Hz 高保真采样 |
| 分析层 | AI-BioMarker 引擎 | HTSF-Attention 时-频-空三域融合特征提取；跨模态对比学习预测免疫状态 |
| 分析层 | 关键指标 | 抑郁筛查 AUC = 0.93；IL-6 预测 r = 0.78 |
| 干预层 | 强化学习闭环决策 | DQN 自动推荐个体化刺激参数（tDCS / tACS / 迷走神经刺激 / 神经反馈）；电流密度自动限幅，安全可控 |

> 感知 → 分析 → 干预全链条闭环，毫秒级响应。

## 三、系统架构：端-边-云三级智能闭环

```
端侧                边侧                  云侧
8 通道干电极头环  →  ARM Cortex-M55+NPU  →  JSL-Gemma 大模型 + AI-BioMarker
采集 EEG/HRV/EDA     边缘实时去噪/预处理      多模态融合分析
集成 tDCS/tACS       ICA 伪迹剔除             生成风险评分 0–100
                     频带能量计算            推荐个体化干预方案
                     压缩特征上传(压缩比≈80%)
        ↑                                              │
        └──────────── 闭环干预指令回传 ←──────────────┘
```

- **端侧：** 8 通道干电极 BCI 头环，采集 EEG / HRV / EDA 多模态信号，集成 tDCS / tACS 刺激模块。
- **边侧：** ARM Cortex-M55 + NPU 边缘 AI，完成实时去噪、ICA 伪迹剔除、频带能量计算与特征压缩（压缩比约 80%）。
- **云侧：** JSL-Gemma 大模型 + AI-BioMarker 进行多模态融合分析，生成 0–100 风险评分并推荐个体化干预方案。

> 感知 → 分析 → 干预 → 再感知，毫秒级闭环。

## 四、核心技术

### 技术一：HTSF-Attention 多尺度脑电特征网络

时-频-空三域统一建模，超越单一频域或空间域分析的精度天花板。

- **频域分支：** 可学习 STFT + 残差 CNN，提取 δ / θ / α / β / γ 能量及耦合特征。
- **空间分支：** 图卷积网络（GCN）提取功能连接特征。
- **时序分支：** Transformer Encoder 提取慢波振荡与微状态序列。
- **跨模态注意力融合层：** 输出 504 维高级特征向量。

**性能指标**

| 任务 | AUC |
| --- | --- |
| 抑郁筛查 | 0.93 |
| MCI 筛查 | 0.89 |
| IL-6 升高识别 | 0.91 |

### 技术二：AI-BioMarker 虚拟免疫组学

用无创 EEG 信号定量推断外周免疫状态——跨越神经-免疫轴的无创桥梁。

- **双塔结构（跨模态对比学习）：**
  - 塔 A：EEG 特征（HTSF-Attention 输出的 504 维特征向量）。
  - 塔 B：免疫 + 多组学特征（基因组 / 蛋白组 / 临床文本，经自编码器降维）。
  - 两塔通过跨模态对比学习映射至共享嵌入空间。

**验证结果**

| 指标 | 结果 |
| --- | --- |
| EEG 预测血清 IL-6 水平 | 相关系数 r = 0.78（n = 240） |
| 免疫异常筛查 | AUC = 0.85 |

> 创新意义：全球首个用 EEG 直接预测外周免疫指标的模型，实现非侵入式虚拟免疫组学。

### 技术三：强化学习闭环干预引擎

自适应个体化刺激，安全可控——千人千方，隐私保护。

- **算法：** DQN + 联邦学习，多中心协同训练，数据不出域。
- **状态空间：** 风险评分、异常脑区定位、历史依从性。
- **动作空间：** tDCS（0.5–2 mA）、tACS（1–40 Hz）、迷走神经刺激、神经反馈难度调节。
- **奖励函数：** 短期看脑电慢波变化，长期看临床量表改善。
- **安全机制：** 电流密度 / 总电荷量自动限幅，绿色安全光盾标识。
