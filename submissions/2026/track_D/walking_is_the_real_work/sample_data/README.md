# Sample Data · 城市色彩存档

赛道 D 的合规要点是 *数据来源透明 + 隐私可追溯*。本目录给出 demo 用的样本说明,**不附带原始照片**,以避免肖像/位置二次披露。

## 推荐复现样本

| 文件名             | 拍摄地           | 主色提示         | 用途           |
|--------------------|------------------|------------------|----------------|
| `juluroad-821.jpg` | 上海·巨鹿路 821 号 | 砖红 / 暮褐     | 街区色彩存档示例 |
| `wukang-mansion.jpg` | 上海·武康大楼   | 赭石 / 灰泥     | 历史保护建筑示例 |
| `hutong-bj.jpg`    | 北京·杨梅竹斜街   | 灰青 / 朱漆     | 跨城市对照示例   |

## 自取数据

复现时请使用 *自己拍摄* 的街景照片,或选取以下合规来源:

- 上海市规划资源局开放数据 (data.sh.gov.cn),CC-BY-4.0
- Wikimedia Commons "Architecture of Shanghai" 分类下,标注 CC0/CC-BY 的图片
- 项目作者本人在巨鹿路 / 武康路 / 愚园路实地拍摄(2026 年 5 月,已获肖像规避)

## 隐私协议

1. 上传到本服务的图片 **不落盘、不外传** —— 仅在内存中喂给 Gemma 4 模型,推理结束即释放。
2. 服务器只持久化 *提取后的调色板 + 用户填写的题字*,EXIF/GPS 元数据在请求边界即剥离。
3. 用户可在 `archive.db` 中按 `place` 主动撤回任何一条标本。
