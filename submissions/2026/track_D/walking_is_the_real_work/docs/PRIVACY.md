# 数据合规与隐私保护说明

> 赛道 D 关键评审项 · 与 `docs/TECHNICAL_REPORT.md` §3.3 对齐

## 数据来源合规

1. **用户自拍内容**:用户授权后通过浏览器拍摄/上传的照片,作为模型推理输入。
2. **历史保护名录**:来源于上海市规划资源局公开的 *历史风貌保护道路名录*,在 `backend/tools.py` 的 `HERITAGE_REGISTRY` 中以代码常量形式静态嵌入。所有数据均在公开数据范围内。
3. **样本图集**:见 `sample_data/README.md`,优先使用 CC0 / CC-BY 资源,严禁使用未授权的第三方图片。

## 隐私保护措施

| 边界          | 措施 |
|---------------|------|
| 上传链路       | 生产部署应在 FastAPI 前配置 HTTPS 反向代理 |
| 服务端处理     | 应用不主动保存或记录原图;框架可能在请求期间使用受控的临时 multipart 缓冲 |
| EXIF / GPS    | 推理前通过 Pillow 解码为 RGB 像素,Gemma 4 不接收 EXIF 元数据 |
| 持久化         | 仅保存模型提取的调色板 + 用户主动输入的文本 |
| 数据撤回       | 当前演示数据库可由部署方按 `place` 字段执行删除;正式版需提供用户侧撤回入口 |
| 日志           | 应由部署方关闭或脱敏反向代理与 Uvicorn 访问日志 |
